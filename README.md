# CRUSH
cereal's rust utility shell

# why CRUSH?
CRUSH is built as a non GNU alternative to bash without being a fork of bash directly.
CRUSH is intended to be used in the MiraOS Linux distro, however it is tested on Arch Linux,
so that you don't have to worry about compatibility.

# does CRUSH work on Windows or macOS?
on Windows the answer is simple, no.
Windows is not a place where i am willing to officially maintain CRUSH.
Windows is not UNIX-like, having a non UNIX operating system to maintain alongside UNIX-likes
would be incredibly annoying and not worth the time if you can run WSL anyways.
if you want to run CRUSH on Windows, either look for ports or use WSL.

for macOS, the answer is a little more complicated.
i don't know if the project will compile and work on macOS, and i don't have any way to test for
macOS, if it works, great, if it doesn't, you're out of luck, i do not plan for offical macOS
support. though forks/PRs are always welcome.

# what is CRUSH's stance on Artificial Intelligence?
Artificial Intelligence can be used in contributions, however there are restrictions.
- you should know what the code does, and be able to explain it.
- the AI is not allowed to generate over 25% of the PR.
- AI assistance is allowed, Full AI generation isn't.
- AI usage must be clearly labeled.
- AI code must be rewritten and reviewed by a human, to ensure quality.
if you are caught not following these guidelines, you will be banned from contributing to CRUSH.
